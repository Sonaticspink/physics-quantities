# ปริมาณทางฟิสิกส์ — เนื้อหา + ควิซ

เว็บช่วยทบทวน **ปริมาณทางฟิสิกส์ 32 ปริมาณ** (ความหมาย · สัญลักษณ์ที่ใช้บ่อย · หน่วย SI · มิติ MLTΘ และ FLT)
พร้อมแบบทดสอบเลือกตอบที่สร้างจากข้อมูลชุดเดียวกัน

สร้างจากไฟล์ส่งออกการสนทนา `chakkrit_tanoi-export-20261011T013605.html`

## ใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # ได้ไฟล์ใน dist/ (static ล้วน ไม่ต้องมีเซิร์ฟเวอร์)
npm run preview  # ลองเปิดไฟล์ที่ build แล้ว
```

Deploy ขึ้น Vercel / GitHub Pages ได้ทันที (static site, output = `dist`)

## ตรวจความถูกต้องของควิซ

```bash
node scripts/check-quiz.mjs
```

ตรวจว่า (1) ทุกคำถามมี 4 ตัวเลือก ไม่ซ้ำ และ index เฉลยตรงกับข้อมูลจริง (2) โหมดมิติไม่มีตัวเลือกที่มิติซ้ำกับเฉลย
(3) ตัวเลือกหลอกทุกตัวเป็นข้อมูลจริงในไฟล์ ไม่ใช่คำมั่ว (4) โหมด "ทำข้อที่ผิดซ้ำ" ให้จำนวนข้อตรง

## โครงสร้าง

```
src/
  data/quantities.js    32 ปริมาณ + มิติ (คำนวณด้วยพีชคณิตมิติ) + ดัชนีสัญลักษณ์ซ้ำ
  data/confusions.js    คำถามชุด "จุดที่มักสับสน" (เขียนจากหัวข้อท้ายไฟล์ต้นฉบับ)
  lib/quiz.js           เครื่องสร้างคำถาม 4 แบบ + การเลือกตัวเลือกหลอก
  lib/store.js          บันทึกความก้าวหน้าใน localStorage
  components/           Material · Quiz · Progress · About · Sym
scripts/check-quiz.mjs  ชุดตรวจควิซ
```

## หมายเหตุเรื่องข้อมูล

- 4 คอลัมน์ตั้งต้น (ปริมาณ / ความหมาย / สัญลักษณ์ / หน่วย SI) และหัวข้อ "จุดที่มักสับสน" มาจากไฟล์ต้นฉบับตรง ๆ
- **คอลัมน์มิติ MLTΘ และ FLT เป็นข้อมูลที่คำนวณเพิ่ม** จากนิยามหน่วย SI ด้วยพีชคณิตมิติ และตรวจไขว้กับหน่วยในไฟล์ 21 จุด
- รูปที่แนบในไฟล์ต้นฉบับเป็นลิงก์ S3 อายุ 15 นาที (หมดอายุแล้ว) จึงไม่ถูกนำมาใช้ — ข้อมูลในรูปถูกแปลงเป็นข้อความแทน
- ควิซสร้างจากข้อมูลอัตโนมัติ ตัวเลือกหลอกดึงจากกลุ่มสัญลักษณ์ที่ใช้ซ้ำ/หน้าตาคล้ายกัน และหมวดเดียวกัน
  จึงไม่มีคำถามที่หลุดออกนอกเนื้อหา
- ความก้าวหน้าเก็บใน `localStorage` ของเบราว์เซอร์เท่านั้น ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชี ไม่มีการส่งข้อมูลออก
